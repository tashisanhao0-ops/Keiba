# 🏇 KeibaSim Pro - 完全自動更新システム セットアップガイド

このパッケージをあなたの **GitHub** と **Vercel (または Netlify)** に連携させることで、**「毎週の最新出走馬・確定枠順・調教・JRA公式オッズが完全自動で更新され、スマホから1タップでいつでも使える環境」** が完成します。

サーバー代などの費用は一切かかりません（**完全無料 / 0円**）。

---

## 🚀 誰でもできる！かんたん3ステップ設定

### ステップ1：GitHubにファイルをアップロードする（2分）

1. **[GitHub](https://github.com)** にログインします（アカウントがない場合は無料登録）。
2. 右上の「**+**」アイコン → 「**New repository**」をクリック。
3. **Repository name** に好きな名前（例: `my-keiba-sim`）を入力し、「**Public**」を選んで「**Create repository**」を押します。
4. 作成された画面にある「**uploading an existing file**」という青いリンクをクリックします。
5. 解凍したこのフォルダの中身（`index.html`, `data/`, `scripts/`, `.github/`）を、**画面の枠の中にそのままドラッグ＆ドロップ**します。
6. 画面下の緑色のボタン「**Commit changes**」を押せばアップロード完了！

---

### ステップ2：Vercelで自分専用URLを作る（1分）

1. **[Vercel](https://vercel.com)** にアクセスし、「**Continue with GitHub**」でログインします（無料）。
2. ダッシュボードの「**Add New...**」→「**Project**」をクリック。
3. 先ほどGitHubで作ったリポジトリ（`my-keiba-sim`）の横にある「**Import**」を押します。
4. 設定はそのままで、青い「**Deploy**」ボタンを押します。
5. **数十秒であなた専用のURL（例: `https://my-keiba-sim.vercel.app`）が完成します！**

---

### ステップ3：スマホのホーム画面に追加する（30秒）

1. 発行されたあなた専用のURLをスマホで開きます。
2. **iPhoneの場合（Safari）**:
   * 下部の共有ボタン（📤）→「**ホーム画面に追加**」
3. **Androidの場合（Chrome）**:
   * 右上のメニュー（︙）→「**ホーム画面に追加**」
4. スマホのホーム画面に「🏇 **KeibaSim**」のアプリアイコンが作成されます！

---

## ⚡ 毎週の自動更新の仕組み（完全メンテナンスフリー）

あなたが何もしなくても、裏側で以下のスケジュールで無料ロボット（GitHub Actions）が自動起動します：

* **毎週金曜日 18:00 (JST)**: 週末レースの枠順確定後に自動起動。最新の枠番・出走馬を反映。
* **毎週日曜日 09:00 (JST)**: レース当日朝の確定オッズを自動取得して更新。
* **毎週日曜日 14:00 (JST)**: 発走直前の最新オッズを最終反映。

更新された瞬間に、Vercelがスマホ側のアプリを勝手に最新に書き換えます。
あなたはただ、**スマホのアイコンをタップしてシミュレーションを見るだけでOK**です！
